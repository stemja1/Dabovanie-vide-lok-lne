1. Architektúra a princíp fungovania

Aplikácia kombinuje moderné desktopové GUI v Tauri v2 (Rust + React + Tailwind) s výkonným výpočtovým prostredím Ubuntu 24.04 v prostredí WSL2, kde prebieha hardvérovo akcelerovaný beh AI neurónových sietí cez AMD ROCm 6.2/6.4.

1

FFmpeg Demuxing & Audio Extrakcia

Izolácia pôvodného slovenského zvuku z videa, normalizácia na 16kHz WAV mono.

CPU / FFmpeg CLI
2

Slovenský ASR (Whisper-SK / faster-whisper)

Automatický prepis slovenskej reči na text s presnými časovými značkami slov a vetných celkov.

ROCm GPU (~5.6 GB VRAM)
3

Preklad SK → ZH (NLLB-200 600M)

Neurónový preklad slovenského textu do zjednodušenej čínštiny (zho_Hans) so zachovaním kontextu.

ROCm GPU (~2.5 GB VRAM)
4

Interaktívny Utterance Metadata Editor

Pozastavenie pipeline v GUI – používateľ môže skontrolovať preklad, upraviť text, rozdeliť či zlúčiť vety.

GUI Interakcia (0 GB VRAM)
5

Čínska Syntéza Reči (Piper / Kokoro TTS)

Generovanie čínskeho dabingu s automatickým prispôsobením rýchlosti dĺžke pôvodných slovenských úsekov.

Piper MIT / Kokoro Apache
6

Lip-Sync Animácia (LatentSync 1.5 + SDPA Patch)

Presynchronizácia pier postavy podľa vygenerovaného čínskeho audia. Pri OOM záchranný fallback na MuseTalk.

ROCm Native SDPA (~7.6 GB VRAM)
7

Finálny Muxing & Audio Ducking

Zmiešanie pôvodného podmazu a dabingu (-14 dB ducking), vpečenie čínskych titulkov a export videa.

FFmpeg Post-processing

2. Požiadavky a prerekvizity (Windows 11)

Pre správne zostavenie a beh na počítači s Windows 11 a AMD Radeon RX 7700 XT sú potrebné nasledujúce nástroje:

1. Windows 11 & WSL2 Hostiteĺ
  • Windows 11 (build 22621 alebo novší).
  • Nainštalovaný AMD Software: Adrenalin Edition s aktuálnym ovládačom.
  • WSL2 s distribúciou Ubuntu-24.04.
# Inštalácia WSL2 z PowerShellu (ako Administrátor):
wsl --install -d Ubuntu-24.04
2. Vývojové prostredie Rust & Node Vývoj
  • Node.js 20+ (LTS) a npm.
  • Rust toolchain (1.78+): nainštalujte cez rustup.rs.
  • Visual Studio 2022 C++ Build Tools (vyžadované pre kompiláciu Tauri na Windows).
# Inštalácia Rustu (PowerShell):
winget install Rustlang.Rustup
rustup default stable

3. Ako aplikáciu skompilovať

Rýchly štart: Vývojový režim (Live Dev Server) Odporúčané

Tento príkaz spustí Vite dev server pre frontend a súčasne skompiluje a otvorí natívne desktopové okno Tauri aplikácie s okamžitým hot-reloadom:

# 1. Prejdite do koreňového priečinka projektu:
cd Dabovanie-vide-lok-lne

# 2. Nainštalujte frontendové závislosti (React, Tailwind, Lucide):
npm install

# 3. Spustite vývojový režim aplikácie:
npm run tauri dev

Zostavenie finálnej Release verzie (.exe / .msi inštalátor)

Pre vytvorenie samostatného inštalačného balíčka pripraveného na distribúciu a produkčné nasadenie použite:

# Vytvorenie optimalizovanej release binárky a Windows inštalátora:
npm run tauri build

# Výstupné súbory nájdete v:
src-tauri/target/release/ai-dubbing-orchestrator.exe
src-tauri/target/release/bundle/msi/AI Dabing Studio_0.1.0_x64_en-US.msi

Spustenie automatizovaných testov (Test Suite)

Projekt obsahuje 23 integračných a jednotkových testov overujúcich VRAM rozpočty, bezpečnosť ciest a parsovanie:

cd src-tauri
cargo test

# Kontrola linteru a formátovania:
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings

4. Návod na použitie krok za krokom

Krok 1: Prvé spustenie a Setup Wizard (Diagnostika) Setup

Pri prvom spustení otvorte záložku "Setup Wizard & Diagnostika". Systém automaticky skontroluje pripravenosť prostredia:

  1. Kliknite na "Spustiť diagnostiku" – overí sa stav WSL2, balíky Ubuntu, PyTorch ROCm a prítomnosť modelov.
  2. Kliknite na tlačidlo "Opraviť / Inštalovať" pri jednotlivých krokoch (WSL2, balíčky, Python venv, Lip-sync repozitáre).
  3. V záložke "Sťahovanie modelov" si jedným klikom stiahnite potrebné váhy (Whisper-SK, NLLB-200, Piper hlasy).

Tip k Setup Wizardu

Inštalátor je idempotentný. Ak niektorý krok zlyhá (napr. prerušený internet), stačí ho spustiť znova – už stiahnuté časti sa nebudú opakovať.

Krok 2: Konfigurácia v Nastaveniach (Settings) Konfigurácia

V pravom hornom rohu otvorte "Nastavenia" a prispôsobte si parametre pipeline:

  • ASR Engine: Whisper-SK (ROCm GPU) pre maximálnu presnosť alebo faster-whisper.
  • TTS Engine: Piper (MIT) alebo Kokoro (Apache 2.0) pre plnú komerčnú bezpečnosť.
  • Lip-Sync Engine: LatentSync 1.5 (najvyššia kvalita) s ponechaným zapnutým OOM Fallbackom na MuseTalk.
  • ROCm SDPA Fallback: Ponechajte zapnuté (ON) – nahrádza nekompatibilný xFormers natívnym PyTorch SDPA jadrom.
  • Pozastaviť pred TTS na kontrolu: Zapnuté – umožní vám skontrolovať a upraviť preklad.
Krok 3: Spustenie dabingu a nahratie videa Pipeline Studio

V záložke "Pipeline Štúdio":

  1. Pretiahnite video súbor (.mp4, .mkv, .mov) do zóny Video Dropzone alebo kliknite a vyberte súbor.
  2. Panel VRAM & RAM Meter vám okamžite ukáže vypočítanú spotrebu pamäte pre zvolený hardvér (RX 7700 XT).
  3. Kliknite na veľké modré tlačidlo "Spustiť AI Dabingový Pipeline".
  4. V reálnom čase uvidíte priebeh jednotlivých fáz a detailné výstupy v Log Paneli.
Krok 4: Interaktívna kontrola v Utterance Editore Kvalita prekladu

Po dokončení fázy 3 (Preklad) sa pipeline automaticky pozastaví a prepne do záložky "Editor Metadát":

  • V tabuľke vidíte zoznam všetkých rozpoznaných viet so slovenským a čínskym textom a časovaním.
  • Priama editácia: Môžete prepísať čínsky preklad, ak chcete použiť iné synonymá alebo upraviť formuláciu.
  • Rozdelenie vety (Split): Ak je veta pridlhá, kliknite na Rozdeliť a zadajte čas delenia.
  • Zlúčenie viet (Merge): Susediace krátke vety môžete spojiť do jedného plynulého celku.
  • Po kontrole kliknite na "Uložiť a pokračovať v generovaní TTS & Lip-sync".
Krok 5: Prehrávač a export hotového videa Finálny výsledok

Po dokončení záverečného muxingu sa v záložke "Prehrávač Videa" sprístupní hotové dabované video s čínskou rečou a synchronizovanými perami. Kliknutím na "Otvoriť v Prieskumníkovi" prejdete priamo k exportovanému .mp4 súboru.

7. Riešenie problémov a časté otázky (FAQ)

Čo ak LatentSync vypíše chybu "Out of Memory" (OOM)? Riešenie

Aplikácia má zabudovaný inteligentný samoliečiaci mechanizmus. Ak LatentSync narazí na VRAM limit, orchestrátor automaticky zachytí OOM chybovú hlášku a bez prerušenia reštartuje fázu s odľahčeným modelom MuseTalk (~4.6 GB VRAM). V nastaveniach tiež môžete znížiť rozlíšenie vstupného videa na 720p.

Prečo je dôležitý "ROCm Native SDPA Fallback"? AMD ROCm Fix

Pôvodné repozitáre ako LatentSync využívajú knižnice xFormers alebo FlashAttention, ktoré sú kompilované primárne pre NVIDIA CUDA a na AMD ROCm architektúrach môžu zlyhať. Náš zabudovaný patch dynamicky nahrádza volania xFormers za natívne jadro torch.nn.functional.scaled_dot_product_attention, ktoré beží na karte RX 7700 XT na 100% rýchlosti.

Ako nájdem vygenerované súbory na disku vo Windows? UNC Cesty

Všetky súbory z WSL2 Linux prostredia sú priamo prístupné z Windows cez sieťovú UNC cestu: \\wsl.localhost\Ubuntu-24.04\home\ubuntu\ai_dubbing_workspace\. V GUI stačí kliknúť na tlačidlo "Otvoriť v Prieskumníkovi".
