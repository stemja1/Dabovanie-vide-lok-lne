1 Prečo vznikli chyby v PowerShell termináli?

Ak sa vám pri prvom spúšťaní zobrazili červené chybové hlášky, tu je presné vysvetlenie, prečo k nim došlo a ako ich jednoducho odstrániť:

❌ Chyba: npm : The term 'npm' is not recognized...

Prečo nastala: Nástroj npm (Node Package Manager) je správca balíčkov pre jazyk JavaScript a je súčasťou inštalácie programu Node.js. Na vašom počítači ešte Node.js nie je nainštalovaný, preto Windows príkaz npm nepozná.

Riešenie: Nainštalujte Node.js (viď Krok 2 alebo Krok 3 nižšie).

❌ Chyba: rustup : The term 'rustup' is not recognized...

Prečo nastala: Rust sa síce úspešne stiahol a nainštaloval cez winget, ale otvorené okno PowerShellu si nepamätalo novo vytvorenú cestu k programu (premennú PATH). Nové programy sú v príkazovom riadku dostupné až po zatvorení a opätovnom otvorení PowerShellu.

Riešenie: Stačí zavrieť PowerShell a otvoriť nový.

❌ Chyba: The requested operation requires elevation.

Prečo nastala: Príkaz wsl --install zapína systémové virtualizačné komponenty vo Windows 11, čo z bezpečnostných dôvodov vyžaduje práva administrátora.

Riešenie: PowerShell je potrebné otvoriť cez "Spustiť ako správca" (Run as Administrator).

🛡️ Čo ak Windows blokuje spúšťanie skriptov? (ExecutionPolicy)

Hláška: File ... cannot be loaded because running scripts is disabled on this system.

Prečo nastala: Systém Windows má z bezpečnostných dôvodov predvolene zablokované spúšťanie .ps1 skriptov.

4 Jednoduché riešenia:

  • Riešenie 1 (Odporúčané): V okne PowerShellu zadajte:
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass a stlačte Enter (povolí skripty iba pre aktuálne otvorené okno).
  • Riešenie 2: Spustite skript priamo s prepínačom:
    powershell -ExecutionPolicy Bypass -File .\install_prerequisites.ps1
  • Riešenie 3: Použite dávkový súbor start_app.bat (dávkové súbory .bat Windows neblokuje).
  • Riešenie 4: Odblokujte súbor príkazom: Unblock-File .\install_prerequisites.ps1

2 Rýchla inštalácia nástrojov (Automatický 1-Click Skript)

Aby ste nemuseli jednotlivé balíky inštalovať manuálne, v projekte je pripravený automatický PowerShell skript install_prerequisites.ps1, ktorý všetko skontroluje, nainštaluje a nastaví.

Automatická inštalácia cez PowerShell (Správca) Najjednoduchší spôsob
  1. Stlačte klávesovú skratku Win + X a vyberte Terminál (správca) alebo vyhľadajte PowerShell v menu Štart, kliknite pravým tlačidlom myši a zvoľte "Spustiť ako správca".
  2. Prejdite do priečinka projektu a spustite inštalačný skript:
# 1. Prechod do priečinka stiahnutého projektu:
cd C:\Dabovanie-vide-lok-lne-main

# 2. Spustenie automatického inštalátora:
powershell -ExecutionPolicy Bypass -File .\install_prerequisites.ps1

Skript automaticky skontroluje a nainštaluje: Node.js LTS, Rust toolchain, Visual Studio C++ Build Tools a WSL2 Ubuntu-24.04.

3 Manuálna inštalácia krok za krokom

Ak preferujete manuálnu inštaláciu cez oficiálne inštalátory alebo jednotlivé príkazy, postupujte podľa týchto krokov:

Krok A: Inštalácia Node.js & npm Frontend

Node.js poskytuje prostredie pre beh webového používateľského rozhrania a nástroj npm.

  1. Stiahnite a nainštalujte verziu LTS z oficiálnej stránky: https://nodejs.org.
  2. Alebo spustite v PowerShell (Správca):
winget install OpenJS.NodeJS.LTS --accept-package-agreements --accept-source-agreements
Krok B: Inštalácia Rust & C++ Tools Backend

Rust kompiluje jadro desktopovej aplikácie a komunikuje s WSL2 a GPU.

  1. Stiahnite rustup-init.exe z https://rustup.rs a spustite ho.
  2. Zvoľte možnosť 1 (Proceed with standard installation).
  3. Nainštalujte C++ Build Tools (ak vás inštalátor vyzve).
winget install Rustlang.Rustup
winget install Microsoft.VisualStudio.2022.BuildTools
Krok C: WSL2 a Ubuntu-24.04 pre AI modely AI Výpočty

V prostredí WSL2 bežia Python skripty pre Whisper, NLLB preklad, TTS syntézu a LatentSync lip-sync s priamou akceleráciou cez AMD ROCm.

# V PowerShell (Spustiť ako správca):
wsl --install -d Ubuntu-24.04

Čo očakávať po inštalácii Ubuntu

Otvorí sa čierne okno Ubuntu, ktoré vás požiada o zadanie nového používateľského mena (napr. user) a hesla. Toto heslo si zapamätajte, používa sa pri inštalácii Linux balíčkov.

4 Ako následne spustiť program po nainštalovaní základných vecí

Akonáhle máte na počítači jednorazovo nastavené prerekvizity (Node.js, Rust a Ubuntu vo WSL2), už nikdy nemusíte nič inštalovať ako správca. Program môžete spustiť kedykoľvek jedným z nasledujúcich spôsobov:

⚡ Najrýchlejší a najjednoduchší spôsob (Každodenné spúšťanie)

V Prieskumníkovi Windows otvorte priečinok C:\Dabovanie-vide-lok-lne-main a dvakrát kliknite na súbor start_app.bat. Tento súbor automaticky pripraví prostredie a otvorí okno aplikácie.

Spôsob 1: Dvojklik na start_app.bat Odporúčané
  1. Otvorte priečinok C:\Dabovanie-vide-lok-lne-main.
  2. Dvakrát kliknite na start_app.bat.

Tip: Kliknite na súbor pravým tlačidlom myši → Odoslať kam → Pracovná plocha (vytvoriť odkaz). Získate tak ikonu programu priamo na ploche!

Spôsob 2: Cez bežný PowerShell Terminál

Otvorte bežný PowerShell (už nie ako správca) a zadajte:

# Prechod do priečinka a okamžité spustenie:
cd C:\Dabovanie-vide-lok-lne-main
npm run tauri dev
Spôsob 3: Vytvorenie samostatného .exe programu (Release Build) Trvalý program

Ak chcete vytvoriť samostatný .exe program, ktorý sa spustí okamžite bez terminálu:

# Spustite v PowerShell (vytvorí samostatný Windows program):
npm run tauri build

# Váš hotový .exe program a inštalátor nájdete v:
src-tauri/target/release/ai-dubbing-orchestrator.exe
src-tauri/target/release/bundle/msi/AI Dabing Studio_0.1.0_x64_en-US.msi

5 Sprievodca inštaláciou modelov (Setup Wizard)

Aplikácia obsahuje vstavaného inteligentného sprievodcu, ktorý za vás automaticky stiahne a nakonfiguruje všetky AI modely priamo v prostredí WSL2.

  1. V hornej lište aplikácie kliknite na záložku "Setup Wizard & Diagnostika".
  2. Kliknite na "Spustiť kompletnú diagnostiku" – aplikácia otestuje prítomnosť WSL2, Python venvu, PyTorch ROCm a modelov.
  3. Kliknite na "Spustiť automatickú inštaláciu". Aplikácia v správnom poradí pripraví:
    • Virtuálne prostredie Python venv v Ubuntu 24.04
    • PyTorch s podporou pre AMD ROCm (RX 7700 XT)
    • Stiahnutie modelov Whisper-SK, NLLB-200 a Piper hlasov
    • Naklonovanie a nastavenie repozitára LatentSync 1.5 a MuseTalk

Idempotentnosť a opakované pokusy

Každý krok inštalátora je bezpečné spustiť viackrát. Ak vám napríklad vypadne internet pri sťahovaní modelu, stačí kliknúť na "Skúsiť znova" pri konkrétnom kroku.

8 Časté otázky a riešenie problémov (FAQ)

Ako zistím, či AMD grafická karta správne funguje v Ubuntu? Diagnostika

Otvorte terminál Ubuntu cez menu Štart a zadajte príkaz rocminfo alebo python3 -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))". Mal by vypísať názov vašej karty (Radeon RX 7700 XT).

Čo robiť, ak pri kompilácii chýba Visual Studio C++? MSVC

Tauri vyžaduje kompilátor C++ od Microsoftu. Spustite v PowerShell (Správca): winget install Microsoft.VisualStudio.2022.BuildTools a pri inštalácii zakliknite "Vývoj desktopových aplikácií v C++" (Desktop development with C++).

Kde sa fyzicky na disku ukladajú spracované videá? Priečinok

Všetky súbory sa nachádzajú v sieťovom priečinku WSL: \\wsl.localhost\Ubuntu-24.04\home\ubuntu\ai_dubbing_workspace\. V Prieskumníkovi Windows stačí túto adresu skopírovať do horného riadku s cestou.
